# FL-04 — Source-Grounded Technical Study Note Workflow

This directory records the design, configuration, five real runs, timing evidence, and limitations of a no-code research-to-writing workflow built with NotebookLM and a Claude Project.

## Contents

| Artifact | Purpose |
|---|---|
| [walkthrough.md](walkthrough.md) | Final workflow walkthrough and evaluation record |
| [prompts.md](prompts.md) | Exact prompts and Claude Project configuration |
| [source-register.md](source-register.md) | Real topics and primary sources used in each run |
| [runs](runs) | Evidence pack, draft, critique, revision, and timing record for each run |
| `screenshots/` | Tool configuration and run evidence captured from the real accounts |

No run is counted as complete until its real tool outputs, timestamps, and human review result have been recorded.
