## Coverage gaps

**Unused Evidence Pack content:**

- **Authentication Bypass Task (§5)** — the only example in the Pack that shows all three check layers on one task: deterministic unit tests, static analysis, and a transcript metric (tool-call count). The draft asserts a combined grading approach in its Short answer but never grounds it in this example, which is the Pack's clearest support for that assertion. *Should be added.*
- **Frustrated Customer Refund (§5)** — pairs an LLM-rubric empathy grade, a required tool call, and a state check on ticket status. This is the Pack's only illustration of a model-based grader in operation, and the draft discusses model-based graders abstractly without it. *Should be added.*
- **Wikipedia vs. Amazon Browser Use (§5)** — DOM extraction versus screenshot interaction chosen per site. The draft never uses it. It is the Pack's only example bearing on tool-strategy variation, which connects to the "too rigid" claim in §3. *Optional; add only if the draft's step 4 needs a second illustration.*
- **Single-turn vs. multi-turn (§4)** — defined in the draft's Core concepts but never used again. The Pack ties multi-turn work to agents modifying environmental state, which is the reason isolation matters. *Should be connected, not merely defined.*
- **Source 2's programmatic implementation and dataset preparation (§7)** — the draft mentions these only in its coverage bullet. Source 2 contributes almost nothing to the draft's body beyond one example. *Acceptable as is, given §7 describes Source 1 as supplying the framework; no addition required.*
- **"Agent Harness (Scaffold)" (§2)** — defined in the draft, then given an unsupported role (C-03) and dropped. Once corrected, the term is defined but unused. *Either integrate it against Pack content or remove the definition.*

## Critique limitations

This audit compares the Draft Note against the Evidence Pack only. It cannot verify:

- Whether the Evidence Pack's quotations are accurate to Source 1 and Source 2, or whether the bracketed ellipses in §3 omit qualifying context — for example, whether the 20-50 task figure carries conditions in the original that §3 dropped.
- Whether the paraphrased definitions in §2 preserve the originals' scope, particularly the agent harness definition on which C-03 turns.
- Whether the six §5 examples originate where the draft's source labels place them, since §5 carries no labels and §7 describes source contributions only in general terms.
- Whether the Pack's "High" confidence ratings were assigned by a stated method, and therefore whether they warrant the unhedged treatment the draft gives them.
- Whether Source 1 or Source 2 in fact addresses the topics the draft treats as absent — harness evaluation, task-level eval migration, eval cost and runtime. The findings above establish that the *Evidence Pack* does not support them, not that the underlying sources are silent. §7's note that large sections of Source 2 were set aside as not relevant means Pack silence is not proof of source silence.
- Whether the framework-selection uncertainty in §6 has been resolved since the sources were captured.
