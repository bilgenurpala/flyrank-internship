## Coverage gaps

**Weather_current tool (§5).** The draft uses the name/description/inputSchema detail in step 2 but strips the example it came from, which is what makes the detail attributable. Should be added — it is the pack's only concrete instance of tool discovery.

**Visual Studio Code as MCP host (§5).** Unused. The draft defines host and server abstractly but never shows the one-host/multiple-clients arrangement the pack illustrates with a Sentry server and a local filesystem server. Should be added; it is the pack's only concrete picture of a host coordinating more than one server, which is directly on the research question's "what context must a tool-using system manage."

**Claude plays Pokémon (§5).** The draft refers to note-taking twice without the example. The pack ties structured note-taking to tracking precise game steps and combat strategies over thousands of turns. Should be added, since it is the only evidence in the pack for note-taking as a long-horizon technique and the draft currently asserts the technique with no example attached.

**Confidence ratings.** All four Supported Claims carry "Confidence: High" in the pack. The draft reports none. Worth adding given A1 — the pack's confidence marking is one of the few attribution signals it does provide.

**Quotation/Paraphrase markers (§2).** The pack labels each definition as Quotation or Paraphrase. The draft honors the distinction in practice but does not surface it. Optional; not a defect.

**"All sources provided relevant material" (§7).** Unused. This is the pack's only statement about aggregate coverage and does not add anything the draft needs. Should not be added.

## Critique limitations

This audit compares the Draft Note to the Evidence Pack only. Without the original sources it cannot verify:

- Whether the four Supported Claims actually belong to the sources the draft assigns them to. A1 establishes that the pack cannot settle this, not that the draft's guesses are wrong — they may well be right.
- Whether the pack's quotations are accurate to their originals, whether they are complete, or whether any were truncated in ways that change meaning. The ellipses in the finite-resource and just-in-time passages are unexamined.
- Whether the pack's paraphrased definitions — context rot, compaction, prompt engineering — faithfully represent the sources, so findings A7 and A10 rest on the pack's wording alone.
- Whether the pack's Uncertainties are the sources' actual silences or the pack author's reading of them. If a source does specify a token threshold or an autonomy heuristic, the draft's preserved uncertainties would be wrong in a direction this audit would not detect.
- Whether the sources describe an ordered process that the pack simply did not record. A8 finds the six-step sequence unsupported *by the pack*; it cannot rule out that such a sequence exists upstream.
- Whether material relevant to the research question was omitted at the pack-building stage. Absent evidence of scope decisions, an omission and a genuine gap in the sources look identical from here.
