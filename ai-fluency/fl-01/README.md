# FL-01 - AI Workflow Audit and Portfolio Foundation

Week 1 establishes how I currently work with AI and what my portfolio must prove. The deliverables connect my real weekly workflow to a focused portfolio claim, a small sitemap, and a reusable Claude Project configuration.

## Deliverables

| Artifact | Purpose |
|---|---|
| [Workflow Audit](workflow-audit.md) | Classifies 15 recurring tasks and defines three reusable targets |
| [Proof Statement](proof-statement.md) | Names one claim, one audience, and one action |
| [Portfolio Sitemap](portfolio-sitemap.md) | Maps the shortest path from landing to proof to contact |
| [AI Workspace Instructions](ai-workspace-instructions.md) | Provides reusable custom instructions for the portfolio workspace |
| [Pressure Test](pressure-test.md) | Records the prompt, critique, decision, and sitemap change |
| [Evidence Checklist](evidence/README.md) | Lists the screenshots that must be captured from real accounts |

## Working Principle

AI is a collaborator and tutor, not the owner of the project. I keep responsibility for decisions, implementation, verification, and what is ultimately submitted.

## Selected Tasks for FL-02 to FL-04

1. Project planning and task decomposition
2. Learning an unfamiliar technical topic
3. Code review and debugging

The measurable definitions of done for these targets are recorded in the workflow audit.
